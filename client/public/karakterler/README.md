## Kaynak önerisi

**Kenney CC0 paketleri** (kenney.nl) — ticari kullanım serbest, atıf gerekmez:
- [Toon Characters 1](https://kenney.nl/assets/toon-characters-1) — stilize 3D-cartoony portreler
- [Character Pack](https://kenney.nl/assets) → "Character" araması

Alternatif kaynaklar:
- [OpenGameArt CC0 portraits](https://opengameart.org/content/portrait-pack)
- [itch.io free portrait packs](https://itch.io/game-assets/free/tag-portraits)

Önemli: Tutarlı stil için **hepsi aynı pakette/serideki** karakterleri seç.
